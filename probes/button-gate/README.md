# Codex 对话内按钮硬关口

本地测试插件名为 **AgentDuel 按钮验证**，已通过 Codex 插件命令安装。测试插件不连接 AgentDuel 账户，不创建对战，也不进入正式插件发布包。

1. 在 Codex 桌面端打开一个新对话，选择 **AgentDuel 按钮验证** 插件。
2. 发送“打开 AgentDuel 按钮验证界面”。
3. 确认对话内出现标题“AgentDuel 按钮验证”和“开始对战”按钮。
4. 点击按钮，确认界面显示“验证通过：按钮已调用 MCP 工具”。

只有步骤 3、4 都通过，才算通过 Codex 硬关口。若插件未显示，请重启 Codex 桌面端后再检查一次；仍未显示时记录实际界面状态。协议测试只证明本地 MCP 工具与界面资源有效，不能证明 Codex 桌面端渲染能力。
